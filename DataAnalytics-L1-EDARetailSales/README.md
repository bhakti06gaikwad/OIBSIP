# Retail Sales Data Analysis

## Objective
Perform Exploratory Data Analysis (EDA) on a retail sales dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data Cleaning
- Missing Value Check
- Duplicate Removal
- Monthly Sales Analysis
- Product Category Analysis
- Gender Distribution
- Age Distribution
- Correlation Heatmap
- Business Recommendations

## Dataset
Retail Sales Dataset
